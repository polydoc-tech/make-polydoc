# Changelog

This file starts at 1.0.0. The package is private and the repo has no version tags: the app is
deployed to Make as a private custom app (the target is under `origins` in `makecomapp.json`),
not published as a package. The changes merged to `main` since 1.0.0 kept that version; they
are in the git history (https://github.com/polydoc-tech/make-polydoc/commits/main).

## 1.0.0 - 2026-06-05

- First version: the PolyDoc connection, the three modules (Convert to PDF, Capture
  Screenshot, Create E-Invoice), the request-body functions in `src/functions/`, and the three
  blueprints in `blueprints/`.
